Demo Flow

  1. 1Digital Locker operator registers data elements in the Consent Manager via the Admin Console.
  2. 2Bank officer logs into the Digital Locker Onboarding portal and registers the bank app — receives a Client ID & Secret.
  3. 3Bank officer uses these credentials in the Bank Portal to communicate with Digital Locker.
  4. 4Bank officer creates a purpose and initiates an authorise request to the citizen to share their data.
  5. 5Citizen opens the Digital Locker app, reviews the itemised data notice, and approves or rejects the request.
  6. 6Bank portal receives an access token scoped to the consent and retrieves the verified KYC data.
  7. 7Digital Locker enforces consent on every API call — only approved elements are returned. Revocation is instant.
